## 検証方法

* `npm test`：28 件。`test/core/frameLayout.test.ts`（7 件）と `test/core/editing.test.ts`（7 件）を新設した。
* ヘッドレス Chrome で検証した。VS Code API のスタブにビルド済みの `webview.js` を読み込み、実データでポインタ操作を再現した。確認した内容は次のとおり。
  * パンしても `UPDATE_DOCUMENT` が送られないこと、枠の上からパンできること
  * 選択しても DOM が維持されること
  * 枠ドラッグで子枠とノードが同じ量だけ動くこと
  * 角ハンドルで右辺だけが変わること
  * 範囲選択から枠で囲み、色を変えられること
  * カードへのドロップで接続されること
  * JSON 破損中は編集がブロックされ、修正後に復帰すること
* 未確認：VS Code 実機（F5）でのキー転送（⌘Z・⌘C/⌘V）と、IME 入力中の挙動。
